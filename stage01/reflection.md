# Stage 1 Reflection

Before using AI, I worked on the SmartCare appointment prototype and ran the provided Python programs. I learned how patient names, practitioner names and appointment times can be stored and displayed using Python. I also worked with lists, dictionaries and functions in the enhanced version.

Using Copilot helped me understand how the appointment-booking code works and some of its limitations. It also suggested an alternative way of creating a simple appointment-booking function. I noticed that AI can make assumptions about what the program should do, so its suggestions still need to be checked against the actual requirements.

I verified the program by running different tests. I tested a normal appointment, a blank patient name, two appointments with the same practitioner and time, and an unusual input using None. These tests helped me identify problems that might not be obvious just by reading the code.

The engineering work still required me to understand the requirements, run and test the program, evaluate the results, identify limitations and decide which improvements were appropriate. This activity showed me that AI can be useful for support, but the software engineer is still responsible for checking the final result.
